## Pragmatic Drag and Drop Example

This repository demonstrates a drag-and-drop interface using the @atlaskit/pragmatic-drag-and-drop library. 
The code provides an example of a column and card system, where cards can be dragged between columns.

### Features

- Draggable Columns and Cards: Columns can be dragged using their headers, and cards can be dragged between columns.
- Drop Indicators: Visual indicators show where a card or column can be dropped.
- Sticky Drop Targets: Drop targets remain sticky, making it easier to drag and drop items.
- Smooth Animations: Custom motion curves and durations ensure smooth animations during drag and drop.

## Installation

To run this example locally, follow these steps:

1. Clone the repository:

> git clone <repository-url>
> cd <repository-directory>

2. Install dependencies:

> npm install

3. Start the development server:

> npm start
