# React Custom Hooks ⚛️

## Better State and Event Handling in React

This repository contains several useful custom React hooks for improving component state management, performance optimization, and event handling.

## What is this?

React hooks let you reuse stateful logic across components.  
These **custom hooks** extend React’s core features to solve common challenges and reduce boilerplate code in your app.

## Why use custom hooks?

- To manage **component size** and respond to layout changes
- To **throttle updates** and improve performance
- To easily work with **Map state** and trigger re-renders
- To detect **outside clicks** and handle interactions (modals, dropdowns)
- To implement **undo/redo state history** in forms or complex UIs

## Covered Hooks

- `useMeasure`
- `useThrottle`
- `useMap`
- `useClickAway`
- `useHistoryState`
