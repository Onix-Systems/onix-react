# Must-Know Expo SDKs for React Native Devs 🚀

Handy examples of essential Expo modules:

1️⃣ `expo-device` — know the device hardware  
2️⃣ `expo-localization` — detect user language and region  
3️⃣ `expo-haptics` — add tactile feedback  
4️⃣ `expo-image-picker` — pick and capture media  
5️⃣ `expo-splash-screen` — control app splash screen  

---

## Why?

- Improve user experience
- Optimize app performance
- Add platform-native behavior easily

---

## Usage

Copy the examples from `expo-sdks.js` into your React Native project with Expo.
